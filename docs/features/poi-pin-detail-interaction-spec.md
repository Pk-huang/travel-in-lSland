# 功能規格：地圖模式／景點中的圖釘功能

## 基本資訊
- **功能名稱**：地圖模式：景點中的圖釘互動
- **優先級**：P2（小功能 / 互動改善）
- **所屬模組**：地圖互動 / 景點模式
- **狀態**：已實作（規格紀錄）

## 背景與目的
當使用者切換到「景點」模式時，地圖上應以圖釘方式呈現可互動的景點，讓使用者能快速辨識不同景點，並透過點擊圖釘直接查看該景點的詳細內容與相關聚焦狀態。

此功能的目標是讓「景點模式」不只是一個資料列表，而是能與地圖視覺化直接互動，提升使用者理解與操作效率。

## 使用者目標
- 在景點模式下快速辨識不同景點
- 透過點擊圖釘查看景點描述與詳細內容
- 讓圖釘與地圖焦點行為保持一致，避免內容殘留或版面錯位

## 功能描述
當使用者進入「地圖模式：景點」時，系統會在地圖上顯示景點圖釘。圖釘應支援以下行為：
- 使用者可透過點擊圖釘查看詳細內容
- 點擊圖釘後，該景點成為目前選取項目，並同步更新地圖焦點與面板狀態
- 點擊圖釘後，詳細內容應於圖釘上方展開
- 點擊地圖空白處時，應清除目前選取狀態並收合詳細內容

## 需求規格（可直接交給 agent 實作）

### 1. 互動行為
- 景點模式開啟時，地圖上應顯示景點圖釘。
- 使用者點擊圖釘時，系統應將該景點設定為目前選取景點，並切換到景點模式的相關資訊狀態。
- 點擊後，應在圖釘上方顯示該景點的詳細內容卡片。
- 若使用者再次點擊同一個圖釘，應切換展開／收合狀態，不應重複建立多份內容。
- 點擊地圖空白處時，應取消目前選取狀態並收合內容卡片。
- 切換到其他地圖模式時，也應清除目前景點選取狀態。

### 2. 視覺與 UI
- 圖釘應以可辨識的地標圖示呈現。
- 選取與 hover 狀態應有更強的邊框、陰影與高亮效果。
- 詳細資訊卡片應以半透明黑底或深色卡片形式呈現，避免與地圖內容衝突。
- 詳細內容應置於圖釘上方，不直接覆蓋在圖釘本體上。
- 當景點被選取時，詳細面板應以更完整的資訊層級呈現，讓使用者能快速掃讀重點內容。
- 詳情卡片應依序呈現主標題、摘要、詳細說明與補充資訊；交通資訊與注意事項應以不同區塊區隔，方便使用者快速掃讀。
- 若景點資料提供多張圖片，面板應顯示圖片區塊並支援上一張／下一張切換；若僅有單張圖片，則以靜態圖片呈現。

### 3. 資料內容與來源
- 點擊圖釘後顯示的內容應包含景點名稱、景點描述、簡短說明、圖片、標籤、交通資訊與注意事項。
- 內容來源應優先使用景點資料中的 `imageGallery`、`descriptionShort`、`descriptionLong`、`tags`、`travel.publicTransport` 以及 `cautionNotes`。
- 若部分欄位缺少資料，應以現有簡述或預設內容做為回退，避免內容空白。

### 4. 實作邊界
- 主要實作範圍為地圖景點圖層與標記元件的互動與呈現。
- 不需要重構整個地圖系統或抽象化其他標記類型。
- 若現有資料結構已足夠，應優先直接接上現有資料，而不是新增新的資料流。

## 互動流程
```text
使用者切換到「景點」模式
    ↓
地圖顯示景點圖釘
    ↓
使用者點擊某景點圖釘
    ↓
系統顯示該景點的詳細資訊卡片
    ↓
系統同步更新選取狀態與景點模式資訊
    ↓
使用者點擊空白處時，清除選取狀態並收合資訊卡片
```

## 驗收標準
- [x] 切換到景點模式後，地圖可顯示景點圖釘
- [x] 點擊景點圖釘後，能顯示詳細資訊卡片
- [x] 點擊景點圖釘後，地圖會維持該景點的選取狀態
- [x] 點擊地圖空白處後，選取狀態會被清除
- [x] 詳細內容卡片與圖釘本體不會互相衝突或跑版
- [x] 點擊後的詳情面板可顯示圖片、摘要、詳細說明與標籤
- [x] 若景點提供多張圖片，面板可支援圖片切換
- [x] 面板可顯示交通資訊與注意事項

## 測試情境
- 正常點擊單一景點
- 點擊不同景點時切換顯示內容
- 點擊空白處時收合資訊卡片
- 連續點擊同一景點時維持穩定互動
- 點擊具有多張圖片的景點時，可正確切換圖片
- 點擊具有交通資訊與注意事項的景點時，可正確顯示對應區塊

## 出界範圍
- 不包含景點圖片預覽的重新設計
- 不包含景點模式的整體導覽流程重構
- 不包含其他地圖標記類型（如路況、測站）的共用抽象重構

## 補充說明
此功能是「景點模式」從靜態圖釘展示，進化為可互動的地圖視覺化入口。後續若要擴充到其他標記類型，也可依照相同規則抽象成共用標記互動模型。
