# 功能規格：地圖模式／天氣中的圖釘功能

## 基本資訊
- **功能名稱**：地圖模式：天氣中的圖釘互動
- **優先級**：P1（核心互動）
- **所屬模組**：地圖互動 / 天氣模式 / 資訊面板
- **狀態**：規劃中

## 背景與目的
當使用者切換到「天氣」模式時，地圖上應該能以圖釘方式呈現各個氣象測站，讓使用者能快速辨識不同區域的天氣狀態，並透過點擊圖釘直接查看詳細資料與聚焦到該位置。

此功能的目標是讓「天氣模式」不只是一個資料列表，而是能與地圖視覺化直接互動，提升使用者理解與操作效率。

## 使用者目標
- 在天氣模式下快速辨識高風險或關注中的測站
- 透過點擊圖釘查看該測站的溫度、風速與座標
- 讓圖釘與右側資訊面板、地圖焦點行為保持一致

## 功能描述
當使用者進入「地圖模式：天氣」時，系統會在地圖上顯示氣象測站圖釘。圖釘應支援以下行為：
- 預設顯示高風險與中風險測站，降低畫面雜訊
- 使用者可透過 hover 或點擊查看詳細資訊
- 點擊圖釘後，該測站成為目前選取項目，並同步聚焦地圖與更新面板狀態
- 點擊地圖空白處時，應清除目前選取狀態

## 互動規則

### 1. 顯示規則
- 天氣模式開啟時，地圖上顯示測站圖釘
- 預設只顯示以下測站：
  - 高風險測站
  - 中風險測站
- 若使用者已選取某測站，該測站應強制顯示，即使其風險等級較低

### 2. hover 規則
- 滑鼠懸停於圖釘時，顯示該測站的簡要資訊浮動卡片
- 懸停狀態應與選取狀態有明顯區分

### 3. 點擊規則
- 點擊圖釘後，執行以下動作：
  1. 設定該測站為目前選取測站
  2. 地圖聚焦到該測站位置
  3. 切換到天氣模式資訊狀態
  4. 顯示該測站的詳細內容卡片
- 若再次點擊同一圖釘，應維持目前選取狀態，不應重複建立多份內容

### 4. 收合規則
- 點擊地圖空白處時，取消目前選取狀態
- 取消後，詳細內容卡片應隱藏

## 互動流程
```text
使用者切換到「天氣」模式
    ↓
地圖顯示測站圖釘
    ↓
使用者 hover 或點擊某測站圖釘
    ↓
系統顯示該測站的詳細資訊卡片
    ↓
系統同步更新地圖焦點與選取狀態
    ↓
使用者點擊空白處時，清除選取狀態並收合資訊卡片
```

## 視覺與 UI 規則
- 圖釘以可辨識的氣象圖示呈現
- 高風險測站使用偏紅/偏強對比色
- 中風險測站使用偏橘/偏暖色
- 低風險測站預設不顯示，避免資訊過度密集
- 選取與 hover 狀態應有更強的邊框、陰影與高亮效果
- 詳細資訊卡片應以半透明黑底或深色卡片形式呈現，避免與地圖內容衝突

## 資料內容
點擊圖釘後顯示的內容應包含：
- 溫度（°C）
- 風速（m/s）
- 緯度／經度
- 風險等級

- [ ] 預設僅顯示高風險與中風險測站
- [ ] 點擊測站圖釘後，能顯示詳細資訊卡片
- [ ] 點擊測站圖釘後，地圖會聚焦到該測站位置
- [ ] 點擊地圖空白處後，選取狀態會被清除
- [ ] hover 與選取狀態具備清楚視覺差異
- [ ] 與右側資訊面板的切換邏輯保持一致

## 測試情境
- 正常點擊單一測站
- 點擊不同測站時切換顯示內容
- 點擊空白處時收合資訊卡片
- 連續點擊同一測站時維持穩定互動

## 出界範圍
- 不包含整體天氣模式重新設計
- 不包含測站資料來源與 API 結構重構
- 不包含多層地圖 / 3D 動畫效果的全面重做

## 補充說明
此功能是「天氣模式」從靜態資訊呈現，進化為可互動的地圖視覺化入口。後續若要擴充到路況或景點圖釘，也可依照相同規則抽象成共用標記互動模型。
